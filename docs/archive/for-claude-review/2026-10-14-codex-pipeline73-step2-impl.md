## 2. Dump publish and `.staging` — HOLD

`rotatePrev` ignores `.staging`, and every expected stage filename is overwritten before the rename loop; an old stage file cannot be published by a *successful* later run merely by being present (`scripts/dumpBeatTabs.js:125-135,193-205`). An exception during a stage write stops before rotation (`:197-201,223`), so the stale file stays isolated. The required Sheet reads and JSON serialization also finish before rotation (`:153-162,183-200`). These are real improvements.

The publish itself is still a sequence: `rotatePrev` deletes `prev/`, then moves old files individually; the new files are renamed individually; `meta.json` is written last (`scripts/dumpBeatTabs.js:125-135,201-217`). A failure inside rotation can leave `prev/` incomplete, and retry starts by deleting that partial `prev/`, losing files already moved. A failure inside the new-file rename loop leaves a partial current directory. On an advancing Cycle the moved meta usually makes readers fail loud until retry, but this does not preserve the previous snapshot or make all files appear together. On a same-Cycle rerun, the old valid meta remains visible while some files have been replaced and others have not. The new pure-helper test exercises none of these faults (`scripts/dumpBeatTabs.test.js:23-38`). Publish a complete generation through one directory-level swap/pointer, or block readers against a generation manifest and prove failure/retry/`prev/` behavior with filesystem fault injection before calling this atomic.

`meta.source` correctly says `25` beat tabs plus the two derived outputs, and `meta.rows` counts *serialized lines* including filtered LifeHistory rows (`scripts/dumpBeatTabs.js:194-212`). The optional-tab empty-file behavior remains in the tab read loop (`:143-162`). However, the existing `civicPetitions.test.js` VM harness omits `module` and stubs only `../lib/sheets`, whereas the new script accesses `module.exports` and imports `../lib/wakePerception` before the VM reaches its optional-tab assertion (`scripts/civicPetitions.test.js:204-227`; `scripts/dumpBeatTabs.js:37,121`). That test will fail even though the new helper test passes; the plan's test list does not claim it was run (`docs/plans/2026-10-11-media-extension.md:271`).
