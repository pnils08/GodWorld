## Brief Attack Checklist (1–6)

1. **Missing producer `causeType` / `effectType` (`grep -rnE "recordRipple_|recordHookRipple_" phase0*/ utilities/`):**
   - **Missing:** `causeType: 'relocation-pressure'`, `effectType: 'housing-pressure/relocation'` (`neighborhoodTrajectoryEngine.js:315-325`).
   - **Present `effectType`s not named explicitly in table:** `effectType: 'carryover'` on `initiative` (`civicInitiativeEngine.js:2085`) and `economic-event` (`economicRippleEngine.js:282`); `effectType: 'divorce'` on `bond-event` (`householdFormationEngine.js:1212`); `effectType: 'heat-wave-health'` (`generationalEventsEngine.js:377`) and `'storm-business'`/`'flood-business'` (`chaosCarsEngine.js:1022`) on `weather-event`.
   - **Phantom in Task 2 table:** `sports` `venue` (`plan:69`) has no producer.
2. **Table marks "code holds a rank" where code does not say so:**
   - `transit-event` `game-day-crowds` (`updateTransitMetrics.js:649-664`) is a computed continuous ridership lift (`0.3 * unsigned * venueShare`), not an authored fixed tag (`0.05`/`0.02`).
   - `initiative-implementation` (`applyInitiativeImplementationEffects.js:722,734,850`) builds an unread `triggers` count (`triggerCount`); `initiative` (`civicInitiativeEngine.js:1849,2000,2089`) never checks `0.8`/`0` and always emits `+1.0` or `-0.6`.
   - `crime` (`applyCityDynamics.js:835-851,1588-1607`) **does** mark level `3` as a wave in code; authored-tag `chaos-event`, `fame-event` (`fame-rise`), `weather-event`, `crisis-event`, `faith-event`, `faith-join`, `youth-event`, `bond-event` (`marriage`) **do** hold `0.05` major / `0.01–0.02` texture in code comments/constants (`buildCityEvents.js:672` and `buildEveningFamous.js:509,522` emit `0.02`/`0.01` without class comments).
3. **`contractSeedUnit_` grouping mixing two scales in one unit group:**
   - Verified across all 25+ producers: `contractSeedUnit_` (`buildContractSeeds.js:138-159`) does **not** currently put two different scales inside one unit group, because `CONTRACT_SEED_UNIT_EFFECT` isolates `business-closure` (`-25/-40`, `level`) from `economic-event` (`sum`), `sports` (`effect`) splits `sentiment` from `game-night*`, `approval-shift` (`sum`) has one producer scale, and all other causes default to `level` (keyed by `'effect:' + eff`).
   - However, at the **class-rule** level (`CONTRACT_SEED_CLASS`), grouping `transit-event` under `tag` applies one rule (`|m| >= 0.05`) to both fixed tags (`service-disruption` `0.05`, `gridlock` `0.02`) and a continuous ridership-lift fraction (`game-day-crowds`). Note also that `economicRippleEngine.js:291` passes un-decayed birth `rlr.impact` (not `currentStrength`) on `carryover` rows, so decaying economic carryovers stay at full birth magnitude in `cause` (`sum`) until expiry.
4. **What removing the cluster-count arm breaks downstream:** See Finding 6 (carry priority `3 -> 2` and `seedHoodMedian_` weights; `faith-event` crisis-response and `faith-join` congregation-surge `>=3` assumptions; `buildLivesSlice.js:315` falling back to insertion order for demoted clusters; `draftContentRows.js:281` `major`-only `.slice(0, 3)` starvation; `buildContractSeeds.test.js:157,463` failures).
5. **Unlisted-kind behaviour (`texture` + `Logger.log` + enumerating test):** Silent runtime fallback on live Sheets — see Finding 5.
6. **Trick code / weakened rules:** See Findings 2 (`contractSeedIsMajor_(unitGroup)` missing `causeType`), 3 (`initiative` always major via `+1.0`/`-0.6`; `stalled` `-0.5` major while `pilot-active` `0.6` texture), and 4 (phantom `sports` `venue`; `fold-applied/approval-shift` permanently `< 0.05`).
