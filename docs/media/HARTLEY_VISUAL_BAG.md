# DJ Hartley — Visual Record Bag

2. **After Confetti** — quiet after noise  
3. **Waterfront Dawn** — city before the crowd  
4. **Bar Stool Eye** — Heinold's / Jack London human moment  
5. **Dugout Steps** — access without inventing faces

8. **Team Assign** — Arman portrait / Brianna neighborhood when story needs it
