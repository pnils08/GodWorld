The pool shuffle already uses `safeRand_(ctx)` (`bondEngine.js:543-553`); both Cycle entry points call the same engine (`phase01-config/godWorldEngine2.js:667,2384`). Removing the pair loop changes draw count and hence downstream outcomes, as expected; a fixed-seed test should prove reproducibility and document draw order. `_bondCompatByKey` is currently populated only for examined unbonded pairs (`bondEngine.js:1138-1150`); unexamined existing friendships use the recomputation path in romance (`:2140-2157`).
