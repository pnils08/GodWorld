# Sgt. Rachel Torres — Safety Bag

## Authority

## Modes (pick 1–2)

1. **Incident Card** — cycle/location/duration/outcome structure  
2. **Classification Gap** — event that doesn't fit the category  
3. **No Report Filed** — what that phrase actually means  
4. **Pattern Analysis** — 2+ related incidents without inventing a crime wave  
5. **OARI vs Traditional** — alternative response when on record  
6. **Roll-Call Reality** — precinct focus language translated for readers  
7. **Scene Before Release** — field observation vs press release (packet-true)  
8. **Witness/Officer Voice** — only attributed packet quotes  
9. **Practical Close** — specific public-safety guidance, not politics  
10. **Ambient Stress Read** — calls that resolve clean but signal pressure
