# Pipeline.68 mechanism review — codex

Scope: read-only adversarial review of the five sourcing modes and Elias Varek node wake. The per-reporter mode list is outside this review. Findings are ranked by consequence; line references are to the current worktree on 2026-10-01. This is a design verdict, not a production proof.

## Findings

1. **BLOCK — A Civis `move` in `Reflection_Intake` cannot reach the proposed target.** The proposed row carries `move/target/read/watching` and `applied=no`, and the plan says the next fire decides whether the move affects a hood or node (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:334-342`). The existing A–K row has no JSON column: F is a 180-character prose snippet, E/H are classified event/affect, and I–K carry bond/tension fields (`scripts/citizen-wake.js:411-424`; `utilities/compressLifeHistory.js:125-133`). The engine reader skips rows without E/H, then reads only those classified tags, snippet, bond, tension and resolution (`utilities/compressLifeHistory.js:289-313`); successful drain applies dial/bond effects and flips `applied=yes` (`utilities/compressLifeHistory.js:620-629`). Putting JSON in F with blank E/H leaves it pending forever; assigning E/H consumes the ordinary reflection while silently ignoring the move. Specify a dedicated typed intake tab or new typed columns plus a validated engine consumer, explicit target resolution, applied/failed status, and replay key. A Node append to a new Sheet is an external direct write and needs its schema/writer documented under the `docs/engine/SHEETS_MANIFEST.md:115-117` rule; `applied=no` alone is not a gate for the proposed business action. If the first cut has no engine consumer, call the move **recorded only**, not an engine-gated move.

2. **BLOCK — Office quotations have no W3 provenance bridge.** Tier 1 proposes `statements[].quote` / `fullStatement` as quotation of record (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:285-290`). Today `collectQuoteAsks` calls `citizenVoice --batch`, validates W2 replies, and passes only those interviews onward (`scripts/cron-desk-run.js:511-545,2640-2651`). W3 builds `manifest.approvedQuotes` only from `interviews[].claims.publishableQuote` with a W2 quote ID and `packet.W2[POPID]` source (`scripts/livedExperiencePacketV2.js:295-305,333-338`); its quote audit only checks text against that manifest (`scripts/livedExperiencePacketV2.js:575-608`). Rhea's INTAKE check independently demands a matching name in `packet.quotes`, not merely a W3 manifest entry (`scripts/cron-rhea-gate.js:505-525`). Thus a fixed office quote inserted into W3 alone either fails the quoted-source gate or tempts a forged W2 backing. Add a distinct `office-record` source type carrying cycle, office slug, statement ID, exact quote text, file path, and holder POPID resolved against `Civic_Office_Ledger`; extend both W3 manifest construction and Rhea backing to validate that type. Use `quote` verbatim; `fullStatement` is separately authored prose and cannot be treated as the same exact quote. The civic JSON schema requires a speaker and quote but does not itself prove the speaker's ledger identity (`scripts/cron-civic-run.js:1275-1284,1300-1307`). The civic path deliberately does not fact-gate its speech (`scripts/cron-civic-run.js:1365-1381`), so a quoted office claim must stay attributed as that office's claim, not become an `approvedFact` about the city.

3. **FIX-BEFORE-BUILD — Mode pools must be fixed before W1 and rechecked before W2; switching only `collectQuoteAsks` leaks proximity.** The design's build list switches mode at `collectQuoteAsks` but leaves W1's `buildAnglePacket` using `candidateRows` (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:322`; `scripts/livedExperiencePacket.js:389-396`). `candidateRows` returns the first nonempty slice pool, then `story.citizens/popids`, then ledger neighbors (`scripts/livedExperiencePacket.js:76-109`); row admission uses a POPID and arbitrary `why`, while `isProximityCandidate` rejects only fixed labels (`scripts/livedExperiencePacket.js:64-73,690-704`). A slice-authored reason such as “educator on the ledger in Rockridge” passes both W1 and W2 even when it denotes only proximity. W2 also falls back from empty W1 candidates to `candidateRows(story,slice)` (`scripts/cron-desk-run.js:423-443`), a fallback pinned by a current test (`scripts/newsroomWakePackages.test.js:400-413`). Build a typed, immutable candidate record from the mode's positive join **before W1**, pass only that set to W1, and require W2 POPIDs to be a subset of it. `named` needs an addressable slice row that names that POPID; `workplace` needs Active roster row plus the leading BIZ_ID; `offices` needs holder/worker and topic ownership; `street` needs the matched current-cycle life line. Reject a row with only hood, bond, story POPID, or a `why` string. Empty remains empty even after rest-cap handling (`scripts/cron-desk-run.js:483-508`).

4. **FIX-BEFORE-BUILD — The `street` rule is underspecified for venue stories and can manufacture a visit.** The plan allows a consumption tag plus “highlight nouns,” including hood, and says only hood-texture seats may qualify on hood alone (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:278,287`). Current evening highlights carry distinct typed classes such as TV slate, movie slate, and venue sighting (`scripts/buildEveningSlice.js:452-479,533-557`). A generic `[Media] caught the recap` line or a line naming the hood can overlap a venue highlight without saying the citizen visited or watched that venue. Exact matcher: require snapshot cycle = assignment cycle, parse each life line's canonical `Y{year}C{cycleOfYear} — [Tag]` or absolute `C{cycle} — [Tag]` stamp to that absolute Cycle (`utilities/compressLifeHistory.js:771-777`), and require an allowlisted consumption tag; compare a normalized **typed highlight entity** (full venue/show/game/event name or stable ID, not shared hood words) against a complete token-boundary phrase in that same line; require the line's action to support the asked predicate (`visited/was at` for venue attendance, `watched/saw` for show or game, `heard/noticed` only for an observation ask). For a hood-texture highlight only, permit the exact hood name plus a line about a local observation, never a venue-attendance claim. If the line says only “caught the recap,” ask about the recap only when the recap itself is the named highlight; otherwise abstain. Preserve the matched line and source as the one W2 FACT. Check `output/simulation_ledger_snapshot.meta.json` against the assignment cycle because the snapshot is a stable filename whose stamp can be retained across later reads (`scripts/dumpLedger.js:73-108`).

5. **FIX-BEFORE-BUILD — `offices` tier 2 is a new service boundary, and silence needs explicit behavior.** The civic path creates full office-voice JSONs through `callVoice`, a local helper that reads a persona directory, runs the civic output contract, validates `statements[]`, and writes a civic file (`scripts/cron-civic-run.js:1255-1263,1269-1307,1451-1486,1492-1496`). `loadVoiceJsons(cycle)` reads only exact-cycle files (`scripts/cron-civic-run.js:1548-1556`); there is no exported single-question desk entry point. Invoking the Sunday civic cron from a desk wake would couple stages and risk a second civic act. Define a separate office-ask adapter with the holder's existing persona, story record, one question, and W2-like validation; it must not call `--stage=voices/projects` or write a new civic decision. When the cycle file is missing, reject stale files; when no statement matches the story's exact initiative/topic, keep tier 1 empty and use the authorized tier-2 adapter only if available. Otherwise file without an office quote and record that silence. `statementsTouching` currently accepts name-substring/topic matches for **project triggering**, which is too broad as quote entitlement (`scripts/cron-civic-run.js:1532-1546`).

6. **FIX-BEFORE-BUILD — The INSTITUTIONAL exception must reach the packet and validator, and only for genuine office sources.** `quoteIneligibility` blocks any role containing `council|mayor|official|director|chief`; `buildReportPacket` sets `quoteEligible=false` and the abstain instruction (`scripts/livedExperiencePacket.js:639-645,707-748`). `prepareInterviewPacket` retains eligibility, and the interview validator rejects quotes when it is false (`scripts/newsroomInterviewContract.js:94-105,159-183`). Therefore an Active roster worker whose RoleType is “OARI Program Director” remains unquotable under `workplace`; “BART Station Manager” does **not** match this regex and is currently quotable. That is consistent with the design's stated exception only for `offices`, but the build must pass validated mode/source kind into `quoteIneligibility` and `buildReportPacket`, then into the W2 contract. Do not globally delete the role block or let a caller-declared `mode='offices'` alone confer authority: require a matching office holder or civic employer roster row and story-topic join first. Office-record quotes should bypass citizen W2 entirely via Finding 2.

7. **FIX-BEFORE-BUILD — Node scheduling and two wakes need separate identity and replay protection.** The ordinary voiced slot can select Varek on any daily fire (`scripts/citizen-wake.js:143-181`), and it writes a page reflection followed by one classified intake row (`scripts/citizen-wake.js:363-378,411-424`). The proposed per-Cycle node wake after the beats dump would intentionally add a second reflection for the same POPID on some days (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:332-342`), so it is not a page collision by itself. It *is* two independent page/intake writes and two ordinary reflection dial inputs unless the node row is separately typed. Give the node page entry and move intake a `(POPID, Cycle, node)` key, check it before any external write, and make retries idempotent across page success / intake failure. Verify `output/beats/meta.json.cycle` and `prevCycle` before diffing: the dump rotates only on a Cycle advance and same-cycle reruns overwrite in place (`scripts/dumpBeatTabs.js:124-153`). Keep the voiced slot eligible as specified, with its own daypart and reflection semantics.

8. **FIX-BEFORE-BUILD — The model and canon-leak gates do not presently establish the node acceptance claim.** The proposed `deepseek/deepseek-reasoner` call is not a tested production route here: `citizen-wake.js` hardcodes `deepseek/deepseek-chat` with 260 output tokens (`scripts/citizen-wake.js:259-267`), and the recorded OpenRouter key-limit 403 blocked a prior civic wiring run (`docs/research/2026-09-15-kimi-civic-lane.md:70-75`). Availability on the current key is unverified; do not assert it works. Name a fallback: the existing production SDK Sonnet 5.5 route that the plan already offers (`docs/plans/2026-09-07-beat-slices-from-sheets-plan.md:339`), behind an explicit route decision and the same output validation; on call failure with no approved fallback, skip the node wake and leave no half-written move. The existing Rhea check is an **Article** gate (`scripts/cron-rhea-gate.js:505-525`), and its raw-decimal scan is explicitly retired (`scripts/cron-rhea-gate.js:258-262`). `lintCivicPackets` checks civic prep prose, not citizen page reflections (`scripts/lintCivicPackets.js:6-22`). Add a node-specific assertion on the generated prose: no raw decimals, dial names, severity scores, POPIDs, sheet/table labels, or model JSON; validate target against the current dump and enforce the Oaks limit. The current Varek LENS/RULES explicitly forbid engine language and unsupplied business acts (`.claude/agents/citizen-voice-elias-varek/LENS.md:20-25`; `.claude/agents/citizen-voice-elias-varek/RULES.md:14,25-29`), so amend those authoritative files through their owner before a node wake loads them.

9. **NOTE — Enum migration is narrow but test-pinned.** The registry currently accepts `people|records`, validates only explicit values, and maps every non-records package to `people` (`scripts/newsroomWakePackages.js:8-10,34-36,85-87`). Direct callers compare only with `records` in `cron-desk-run.js:416` and `cron-desk-writer.js:797`; no production caller found that branches on literal `people`. The test **does** pin Trevor to `people` and five records seats to `records` (`scripts/newsroomWakePackages.test.js:146-151`). Change the validation enum and `sourcingFor` together, make absent = `named`, and test unknown-value rejection plus every current registry package (25 keys in the worktree checked for this review). The writer's `RECORDS_PIECE` depends on both `sourcing==='records'` and an empty approved-quote manifest (`scripts/cron-desk-writer.js:793-800`); verify office or other quoteless pieces take the intended prose route without borrowing a nonexistent street scene.

**Verdict: do not ship the design to build as written.** Resolve Findings 1–8 in the mechanism spec; the per-reporter list can be ruled separately.
