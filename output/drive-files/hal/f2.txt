-------------------------------------------------------------------------------------
1. NAMING CONVENTION
-------------------------------------------------------------------------------------
Pattern:  YYYY[-MM][-DD]__desk__subject-entity__doc-type__version.ext


  - Facets are separated by a DOUBLE underscore ( __ ). Words WITHIN a facet use hyphens ( - ).
  - Date: the article's in-universe dateline where its header states one
    (e.g. "Oakland, California — April 2040" -> 2040-04). Otherwise the Drive created date.
    Month/day are included only when known.
  - desk: origins | legacy | features | profiles | id   (editorial desk / section).
  - subject-entity: the primary player/person/team the piece is about
    (e.g. darrin-davis, oakland-athletics, hal-richmond).
  - doc-type: origin-profile, comparison-essay, feature-column, season-essay,
    injury-feature, image-manifest, canon-record, press-id, portrait, letters-column,
    wedding-chronicle, etc.
  - version: v1, v2, ...  (all current files are v1).
  - ext: real extension. ~20 text files currently have NO extension and would gain .txt;
    native Google Docs are shown with a .gdoc placeholder (they carry no Drive extension).


-------------------------------------------------------------------------------------
2. TAG TAXONOMY (namespaced  #facet/value)
-------------------------------------------------------------------------------------
Facets: sport, league, team, player, position, journalist, person, role, type, series,
season, era, time, geo, theme, compares (real players referenced), award, publication,
media, author, status, cycle, popid, doc-id, internal.


Baseline applied to every article:
  #sport/baseball #league/mlb #team/oakland-athletics #geo/oakland #era/dynasty
  #author/hal-richmond #cycle/pre-cycle   (+ #publication/bay-tribune where applicable)


CYCLE RULE (STRICT): a #cycle is a specific sim-engine run. A piece is tagged with a
cycle ONLY if its own header explicitly declares one. NO file in this corpus declares a
cycle, so EVERY item is tagged #cycle/pre-cycle. No cycles were invented.
Note: doc-ids (e.g. 2040-Hal-03) and POPIDs (e.g. POP-00001) DO appear in some headers
and are tagged as #doc-id/... and #popid/... — these are not cycles.
