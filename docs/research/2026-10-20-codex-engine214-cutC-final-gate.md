## Evidence and limits

1. **Fold.** `git diff a137ea9b 72dacd68` changes only the two requested engine clauses: repeated chaos outcomes collapse per kind (`phase05-citizens/applyBusinessDynamics.js:585-589`) and `S.hoodSpots` follows the final log (`:765-773`). The comment and STUB reads no longer attribute the field to `hoodReactionMult_` (`phase05-citizens/generateCitizensEvents.js:207-214`; `docs/engine/ENGINE_STUB_MAP.md:1905-1914`; `docs/engine/ENGINE_STUB_REVERSE.md:211`). Tests add the duplicate event, final-log throw, published FNV-1a/fmix32 vectors and forced tie, and a Claremont-only parent pulse (`scripts/businessOwnerDials.test.js:151-192`; `scripts/testNeighborhoodLoop.js:798-808,833-847`). I inspected the tests; I did not rerun them.
2. **Ordinary-fire fold.** B and B2 `.lines.tsv` compare byte-for-byte equal; both receipts report 2,373 lines, SHA `330ba1da…`, and one spot draw (`output/engine-sheet/2026-10-20-e214c-receipt-B-c113.json:2-13`; `…-B2-c113.json:2-13`). The diagnostic identifies B2 as `72dacd68`, a PASS fire, and the same digest (`output/engine-sheet/2026-10-20-e214c-diag.log:2-17`). A's line set also equals the earlier Cut B B leg; the pair log records stage 15 A and Cut C B from the reset (`output/engine-sheet/2026-10-20-e214c-pair.log:2-34`). This does not exercise the final-log throw or repeated chaos on the bench.
3. **Real reach.** Baylight has four quiet holders and one drawn Down line; Ivy Hill has nine quiet holders plus four shed-eligible holders and zero draws (`output/engine-sheet/2026-10-20-e214c-receipt-B-c113.json:56-92,571-620`). The one line names its holder's spot and is graded `Neighborhood-Outabout-Down-S` (`output/engine-sheet/2026-10-20-e214c-receipt-B-c113.lines.tsv:797`); the receipt reports zero wrong-spot lines and no known-citizen strays (`…-B-c113.json:6-13,83-90`). The `eligibleByEvent` field counts holders, not participated/offered entries, and the collector scans saved lines; it does not tap the live generator's pool or pulse (`output/engine-sheet/2026-10-20-e214c-receipt.js:56-63,67-96`). A spot line pulses only when it is the citizen's first draw (`phase05-citizens/generateCitizensEvents.js:3791-3801`); the saved TSV is sorted, so its grade cannot prove a pulse occurred (`output/engine-sheet/2026-10-20-e214c-receipt.js:67-71`).
4. **Probe and sparsity.** The probe adds four chaos outcomes, a recovery, and lifts on selected food spots; quiet/shed come from carried state. Its harness lacks earlier phase fields and explicitly calls its spot share an upper bound (`output/engine-sheet/2026-10-20-e214c-drawprobe.js:1-10,75-88`). Across 100 seeds it reports 263.9 offered citizens/Cycle, 15.9 filtered spot entries/Cycle, mean usable-pool mass 90.4 and spot share 0.0268; every event has nonzero draws, from shed 0.10 to inspection closure 6.45 per Cycle (`output/engine-sheet/2026-10-20-e214c-drawprobe.json:42-78`). In real C113, the only listed business closure hit BIZ-00079 and no spot line of that kind drew; lift eligibility and whole-pool weight are expressly unobservable (`output/engine-sheet/2026-10-20-e214c-receipt-B-c113.json:8-13`). Zero in a hood with no event-bearing spot means no eligible spot; Ivy's zero means eligible holders, no draw. Neither means a failed selection mechanism.
5. **Divergence.** Offline comparison of the saved `|source:` lines in snapshot ledger order finds the first A/B difference at row 8, POP-00009, Downtown; A/Bnolift first differ at row 298, POP-00347, Baylight. The latter is independently the first snapshot holder whose ranked spot has news (`output/simulation_ledger_snapshot.jsonl:8,298`; `output/engine-sheet/2026-10-20-e214c-receipt-A-c113.lines.tsv:21,751-753`; `…-B-c113.lines.tsv:22,751-752`; `…-Bnolift-c113.lines.tsv:21,751-753`; `phase05-citizens/generateCitizensEvents.js:223-258`). That supports an added Downtown lift offer shifting a shared RNG stream; it does not directly observe `barTerm` or per-citizen draws. It would be wrong if a same-baseline run showed no positive Downtown lift, another input changed before row 8, or Bnolift diverged before its first eligible holder. The +64 A→B LifeHistory rows are therefore traced plausibly, not causally isolated by a pool/RNG tap (`output/engine-sheet/2026-10-20-e214c-receipt-A-c113.json:2-5`; `…-B-c113.json:2-5`). Do not run `output/engine-sheet/2026-10-20-e214c-diverge.js` for this read-only task: it reads Sheets (`:13-15`).
6. **Push tree.** The stage 15 and stage 16 manifests differ on only the two named files; stage 16 hashes match `72dacd68` for both (`output/engine-sheet/stage15-e214b.sha256:39,49`; `output/engine-sheet/stage16-e214c.sha256:39,49`). The copied script checks fresh PROD against stage 15, compares each live file with `3ed34b61`, writes both from the chosen commit, compares the entire stage with the pinned manifest, checks the deployment ID and served version, then pulls back and compares again (`output/engine-sheet/2026-10-20-push-e214c-prod.sh:12-40`). Because it pins `realpath` rather than a committed digest (`:14-15`), an altered manifest at that path plus matching altered source could authorize a different tree; the current tracked manifest and both source files were clean and matched. Pull-back occurs after deploy, so a mismatch then is a rollback trigger, not pre-deploy prevention (`:32-40`).
7. **Live watch.** Expect a PASS C113 with no new engine or persistence errors, only factual spot lines for a citizen's selected open food/retail spot, `Neighborhood-Outabout-Up|Down-*` by fact, and a parent-hood ±1 pulse only if that line is the first draw (`phase05-citizens/applyBusinessDynamics.js:713-720`; `phase05-citizens/generateCitizensEvents.js:242-258,2817-2822,3791-3801`). The bench's single quiet line is not a live-count target; live C113 uses live state and sports reach. Inspect typed line, spot, tag, pulse, and saved hood readback before accepting. On rollback, restore exactly the two Apps Script files from `3ed34b61` with a guarded deployment/readback; code rollback alone does not erase an already-written C113 line or pulse (`docs/plans/2026-10-10-engine-214-mood-per-hood.md:230-234`).

**Final PROD gate: HOLD.** Source fold and current push tree are reviewable, but the reach contract still lacks real-fire offered/filtered/whole-pool and pulse receipts. Obtain those from an authorized C113-equivalent observation or explicitly change the acceptance contract before claiming PROD SHIP. No live proof was performed here.
